# DP_3D_Works

Учебный программный рендерер кубических блоков на PascalABC.NET.
Никаких библиотек 3D — только перспективная проекция, повороты и заливка
многоугольников через GraphABC.

## Требования

* [PascalABC.NET](https://pascalabc.net/) 3.8 или новее (Windows)
* Модуль `GraphABC` входит в стандартную поставку

## Запуск

Откройте в PascalABC.NET и нажмите F9:

| Файл | Что показывает |
|---|---|
| `3D_v1.pas` | Перспективная проекция и алгоритм художника. Облако из 512 блоков вращается вокруг точки, сами блоки остаются выровненными по осям. |
| `3D_v2.pas` | Поворот самих блоков вокруг своих центров, отсечение задних граней и освещение по Ламберту. |

`Render3D.pas` — общий модуль с математикой и отрисовкой; отдельно не
запускается. Он должен лежать в одной папке с демонстрациями.

Выход из любой демонстрации — `Esc` или закрытие окна.

## Система координат

```
X — вправо, Y — ВНИЗ, Z — от камеры вглубь сцены.
```

Камера стоит в начале координат и смотрит вдоль `+Z`. Блок `(X, Y, Z)`
занимает куб `[X..X+1] x [Y..Y+1] x [Z..Z+1]`, то есть его ближняя грань
лежит на `Z`, а дальняя — на `Z+1`. Ось `Y` направлена вниз, как на экране,
поэтому тройка осей левая — это учтено в порядке обхода вершин граней.

Экранные координаты считаются как `мировая / Z * Focal + центр окна`:
чем больше `Z`, тем меньше объект.

## Что уже сделано

* Перспективная проекция с отсечением по ближней плоскости
* Поворот блока вокруг собственного центра
* Отрисовка только обращённых к камере граней (их не больше трёх)
* Сортировка блоков по глубине — алгоритм художника
* Направленное освещение с рассеянной составляющей

## Планы

* Отрисовка только видимых блоков — отсечение закрытых соседями
* Отражения
* Прозрачные блоки, с учётом прозрачности при поиске видимых блоков
* Отсечение граней по ближней плоскости вместо пропуска блока целиком
* Z-буфер вместо алгоритма художника — убрал бы артефакты на пересечениях
